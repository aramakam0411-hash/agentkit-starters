# AgentKit AI Project Starter

A free project folder and two reusable skills for turning an AI app idea into a clear first build.

Start with a booking page, an enquiry assistant or a small research tool. This kit helps you specify the useful result, ask an agent to build the smallest demo, and check what it actually does.

## Start here

1. Download this repository as a ZIP, or clone it.
2. Copy [the project brief](templates/project-brief.md) into your project and fill in its first six fields.
3. Give your assistant that brief and the [first build prompt](prompts/first-build.md).
4. Try the result with the [demo review](templates/demo-review.md).

The [dog walking example](examples/dog-walking/project-brief.md) shows a filled brief. It is a fictional example, not a finished booking app or a business result.

## What is included

* [Project brief](templates/project-brief.md): customer, useful output, scope and missing facts.
* [First build prompt](prompts/first-build.md): turn the brief into a small visible demo.
* [Improve the result](prompts/improve-result.md): change the demo using actual feedback.
* [Demo review](templates/demo-review.md): check the main task, difficult inputs and what is mocked.
* [AI project brief skill](skills/ai-project-brief/SKILL.md): turn a rough idea into a buildable brief.
* [Demo review skill](skills/demo-review/SKILL.md): assess whether a prototype does the promised job.

The skills are plain Markdown instructions in SKILL.md format. You can give a skill file to your assistant directly. Automatic discovery and installation depend on your chosen agent or editor. This download does not install plugins, run code or connect accounts.

## Use it on a real project

Change the example's audience and result before asking an agent to build. Keep your actual prices, testimonials, availability and business claims explicit. A demo can use clearly labelled sample data while those facts are missing.

The kit contains instructions and templates. It has no model, hosted app or API key. Your chosen AI tool may have its own usage costs. We checked the files, links and skill structure; we have not demonstrated that every model will produce a working app from them.
