# A simple dog walking booking enquiry page

This is a fictional example for adapting the starter. No prices, business claims or live booking service are supplied.

**Who is it for?** A local dog walking service and owners who need to ask about a walk.

**What task do they want to finish?** A visitor wants to send a clear booking enquiry without guessing which details to include.

**First useful result:** A page with an enquiry form and a readable enquiry preview. The visitor can edit the preview before copying it.

**Input:** Dog name, area, requested day, walk preference and optional notes.

**Outside the first version:** Payments, confirmed availability, automatic sending, account creation and recurring bookings.

**Success:** A visitor fills in the essential fields, gets a clear enquiry draft, corrects a detail and copies the corrected draft.

Use a simple local page for the first demo. This version needs no model. If an owner later wants a free text assistant, ask which provider they want and keep confirmed availability under owner control.

Missing area or day should ask for the missing information. A requested date is an enquiry, not a confirmed booking. Unknown prices and testimonials stay absent. For sample names, visibly label them as fictional.
