# Ask your agent to build the first useful version

Copy the prompt below and attach your filled project brief.

```text
Use my project brief to build the smallest demo of the main task.
Keep my audience, chosen tools and intended output.
If a missing fact changes the core behavior, ask me one focused question.
Otherwise state a reasonable assumption and continue.

Show the useful result early. Prefer a short complete path over many empty pages.
Use clearly labelled fictional examples for unsupplied business facts.
Keep real prices, testimonials and availability unknown unless I supplied them.
Make loading, empty and error states understandable where those states apply.
Use my existing authorization for external services; this prompt grants no new
permission to send messages, make payments or publish the app.

Run the project locally if your tools support it. Try my normal example and
one missing input against the actual result. Fix the main task if it fails.
Tell me how to open it, what worked, what is simulated and what remains.
```
